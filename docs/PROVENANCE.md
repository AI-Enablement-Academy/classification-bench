# Source and reuse

This project grew out of [candidate-experience-benchmark](https://github.com/adambkovacs/candidate-experience-benchmark), whose repository was formerly called recruitment-feedback-demo. The initial standalone extraction uses the lessons and contracts documented at source commit `85886aff7af7c80d01bafa7396f30e977967cbf6`:

- [Harness specification](https://github.com/adambkovacs/candidate-experience-benchmark/blob/85886aff7af7c80d01bafa7396f30e977967cbf6/docs/HARNESS_SPEC.md)
- [Framework research](https://github.com/adambkovacs/candidate-experience-benchmark/blob/85886aff7af7c80d01bafa7396f30e977967cbf6/docs/HARNESS_RESEARCH.md)
- [Repeatability design](https://github.com/adambkovacs/candidate-experience-benchmark/blob/85886aff7af7c80d01bafa7396f30e977967cbf6/docs/REPEATABILITY_PLAN.md)
- [Development findings](https://github.com/adambkovacs/candidate-experience-benchmark/blob/85886aff7af7c80d01bafa7396f30e977967cbf6/docs/FINDINGS.md)

The original results remain in that repository. This foundation contains newly written generic code and a small fictional product-classification fixture. No credentials, private account metadata, raw candidate records or model weights were copied. The fixture's supplied outputs are authored examples, not model responses.

The MIT notice retains the source project's attribution. Third-party frameworks and models are not bundled; their licenses and interfaces must be checked before adoption.
